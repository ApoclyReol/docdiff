# v1.6.4 — Your documents stay with you

- **Privacy up front.** A new section on the start page, "Your documents stay with you", sums up what sets Doc Diff apart from online comparison services: no upload (the browser blocks every network connection from the page), works offline as a single HTML file, nothing stored or shared, and you can check all of this yourself. The line below the buttons now starts with "No upload · Works offline".
- **Clearer search results and link previews.** The page title, description and link preview images now say that Doc Diff runs locally, without uploading, and works offline.
- **No light flash in dark mode.** The dark theme is now set before the page first appears. Before, the start page could briefly show light drop zones and buttons that then faded to dark.

Download `DocDiff.html` below and open it from disk. It works without an internet connection.
