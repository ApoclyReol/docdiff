# v1.6.3 — Faster start, a clearer first screen, reviewed changes that look done

- **Faster start.** The PDF and Word readers (about 1 MB of JavaScript) are still part of the single file, so everything works offline as before, but they now start only when a PDF or Word file is first opened. Opening the page no longer waits for them.
- **First screen of the start page.** On screens tall enough, the drop zones sit centred, "How it works" sits at the bottom edge, and an arrow below leads on to what Doc Diff can and cannot do. Lower windows keep the plain page flow.
- **Reviewed changes look done.** An accepted change reads as plain text with a green edge and a check mark; the removed words stay quietly struck through on the old side. A rejected change has a solid neutral edge and a cross. Nothing fades out any more, and no text moves.
- **Current change in blue.** The change you are on is marked in the selection blue instead of grey, in the document, the list and the overview bar.
- **List toggle.** On the desktop a plain sidebar icon at the right end of the top bar shows and hides the list of changes. Tablets keep the "List" button, which opens the list as a sheet.
