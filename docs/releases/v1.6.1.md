# v1.6.1 — Identical columns, calmer start page, more room on phones

## Comparison

- **Unchanged paragraphs wrap identically on both sides.** The new version's text column was up to 42px narrower than the old one (review margin, scrollbar and divider only on the right), so the same text broke into different lines. Both columns now have exactly the same text width at every window size.
- **More room for text on phones.** The accept, reject and edit buttons sit in a labelled row just above the bottom bar, within reach of the thumb, instead of a button column next to every paragraph. The text column is about 8% wider, with fewer hyphenations; selecting a paragraph still never moves any text.

## Start page

- **Clearer hierarchy:** a larger headline and lead text, body text at reading size.
- **Less on the screen:** one short line under the headline, the supported formats named once under the two file slots, "View example" as the only button next to them, "Paste text" and "Open saved work" as quiet text buttons, and the trust points in one line instead of three badges.

## Type

- One small type scale (13, 14, 15.5, 16, 17, 19px, plus the start page headings) instead of thirteen sizes. Header and footer lines in the document are no longer set smaller than the rest of the text.
