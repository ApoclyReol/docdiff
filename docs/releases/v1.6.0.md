# v1.6.0 — Final version in your own Word format, trustworthy exports

This release is about what you take away from a review: the final version, ready to send, in the format of your own document.

## Export the final version

- **Word in the original format.** When the new version is a `.docx`, Doc Diff writes your decisions straight into that file: accepted changes stay, rejected changes get the old wording back, and your own edits are applied. Styles, numbering, links, footnotes, tables and page layout stay as they are; paragraphs you did not touch stay unchanged. Before the file is saved, Doc Diff reads it back and checks the text. If a change cannot be written safely (for example inside a footnote or a text box), it creates a clean Word document instead and tells you.
- **Word with tracked changes on your original.** The same, with every still-open change as a real Word revision: accept or reject the rest in Word or LibreOffice. "Reject all" gives back the old version, "Accept all" the final one.
- **PDF of the final version**: a clean document without marks.
- **Copy or save as text**: the final version as plain text.

## Export the comparison

- **PDF side by side** (landscape, old and new in two columns) or **PDF inline** (portrait, changes marked in the text).
- **Clearer export menu**: "Final version" and "Comparison", each with a one-line explanation of what you get. HTML report, Markdown and text are under "More formats".

## Trust

- **Exports count exactly like the change list.** A header or footer change that repeats on every page is one change everywhere, with its page range ("p. 1–3").
- **Word documents contain only your document.** The summary and header/footer changes go into a Word comment instead of the text, so "Accept all" leaves a clean document.
- **No misleading pairs.** Changes joined only by a hyphen or a space now read as one replacement ("Standard-Berichtswesen" → "Echtzeit-Nachtragsmanagement, Preisspiegel") instead of fragments paired word by word.
- **Headings stay headings** after you reject a change.
- **Saved work keeps the Word file**, so the original-format export still works after you open a `.docdiff` file again.
