2. Dokumentenvergleich ausschließlich lokal im Browser (Keine Übertragung von Dokumenten)

Wenn du in Doc Diff PDF-, Word- (.docx) oder Textdateien auswählst, per Drag-and-Drop ablegst oder Text einfügst, werden diese Daten ausschließlich lokal im Arbeitsspeicher (RAM) deines Browsers gelesen und verglichen. Es findet keinerlei Upload auf einen Server statt. Weder ich noch GitHub oder sonstige Dritte erhalten Zugriff auf deine Dokumente, Vertragstexte oder Dateinamen.

Technisch ist dies zusätzlich durch eine strikte Content Security Policy (connect-src 'none'; form-action 'none') im Kopf der HTML-Datei abgesichert: Dein Browser unterbindet damit technisch jede ausgehende Netzwerkverbindung aus der Anwendung heraus. Alle benötigten Parser (PDF.js, Mammoth.js, jsdiff) sowie die verwendeten Schriftarten (Geist) sind direkt in der einzelnen HTML-Datei eingebettet.

Es werden keine Dokumentinhalte oder Einstellungen in localStorage, sessionStorage, IndexedDB oder Cookies gespeichert. Sobald du auf „Leeren“ klickst oder den Browser-Tab schließt, werden sämtliche geladenen Texte aus dem Arbeitsspeicher verworfen.
