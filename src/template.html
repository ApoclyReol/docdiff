Dokumente mühsam einfach vergleichen.

PDF, Word oder Text: Jede Änderung wird Wort für Wort markiert. Ihre Dateien verlassen dabei nie Ihren Computer.

  • Kostenlos & Open Source (MIT)
  • Keine Uploads – alles läuft lokal im Browser
  • Keine Werbung, kein Tracking, keine Cookies

Sie können auch beide Dateien auf einmal hierher ziehen – die erste gilt als alte Fassung.

So funktioniert’s

  1. 1Zwei Fassungen wählen Als PDF, Word-Datei oder eingefügten Text. Die Dateien werden nur in diesem Browser-Tab gelesen.
  2. 2Änderungen durchgehen Entferntes ist rot durchgestrichen, Neues grün markiert. Die Liste rechts führt von Änderung zu Änderung.
  3. 3Ergebnis sichern, wenn Sie es brauchen Als Word-Datei mit markierten Änderungen, als PDF oder als Bericht speichern.

Was es kann – und was nicht

Kann

  • PDFs mit Textebene, Word-Dateien (.docx) und reinen Text vergleichen
  • Änderungen Wort für Wort zeigen – auch geänderte Zahlen, Daten und Beträge
  • Seiten wie im Original anzeigen; wiederkehrende Kopf- und Fußzeilen werden ausgeblendet
  • Verschobene Absätze als „verschoben“ kennzeichnen
  • Ohne Internet arbeiten – als einzelne HTML-Datei

Kann nicht

  • Gescannte PDFs lesen – es gibt keine Texterkennung (OCR)
  • Alte Word-Dateien (.doc) öffnen – bitte vorher als .docx speichern
  • Formatierung vergleichen – Fett, Kursiv, Tabellenlayout und Bilder werden ignoriert, verglichen wird nur der Text

Häufige Fragen

Wie kann ich prüfen, dass nichts hochgeladen wird?

Die Seite enthält eine Sicherheitsregel (Content-Security-Policy), mit der Ihr Browser jede Netzwerkverbindung aus der Seite heraus sperrt. Ihre Dateien werden nur im Arbeitsspeicher dieses Tabs gelesen und beim Schließen verworfen.

So prüfen Sie es selbst: Öffnen Sie die Entwicklerwerkzeuge Ihres Browsers (F12), wählen Sie den Reiter „Netzwerk“ und laden Sie dann ein Dokument – es erscheint keine Anfrage. Oder laden Sie die Offline-Datei herunter, trennen Sie die Internetverbindung und öffnen Sie sie: Alles funktioniert weiter.

Kann ich Doc Diff offline nutzen?

Ja. Laden Sie DocDiff.html herunter (eine einzelne Datei, etwa 2,5 MB) und öffnen Sie sie per Doppelklick im Browser – ohne Installation und ohne Internet.
